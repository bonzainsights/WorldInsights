# Country registry

The global ISO country and territory registry is generated by `worldinsights.country_registry` from the exactly pinned dependency `pycountry==24.6.1`.

The registry contains 249 ISO-3166 entries with:

- stable dense WorldInsights geography IDs;
- alpha-2 and alpha-3 codes;
- three-digit M49 map join codes;
- ISO names and optional official names.

The original MVP IDs are permanently preserved for Germany, Nepal, and the United States. Territory and sovereign-country classification is intentionally left for a separate curated integration step.
